## 特性

- **知识库** — 9 大分类，55+ 篇技术笔记，前端实时搜索、大纲跳转
- **作品展示** — 摄影相册、视频作品
- **工具库** — 6 大类精选工具 / 网站导航，支持关键词搜索
- **响应式** — 桌面、平板、手机自适应，暗色模式支持
- **零依赖** — 纯静态文件，无需服务器，支持 `file://` 直接打开

## 技术栈

| 层级 | 技术 |
|------|------|
| 结构 | HTML5 语义化标签 |
| 样式 | CSS3（变量 / Flex / Grid / 媒体查询） |
| 交互 | 原生 JavaScript（ES6+） |
| 渲染 | Marked.js（CDN，Markdown → HTML） |
| 部署 | GitHub Pages / Cloudflare Pages |

> 无 React、无 Vue、无构建工具，所有内容内嵌于前端 JS。

## 项目结构

```
├── index.html              # 主页

├── works.html              # 作品展示

├── danmaku.html            # 弹幕墙
├── style.css               # 全站样式

```
