# 影评文件夹说明

## 目录结构

```
reviews/
├── movie/    ← 电影影评
├── tv/       ← 影视（剧集、纪录片）
├── anime/    ← 动漫
└── TEMPLATE.md  ← 新建影评时复制这个模板
```

## 新增一篇影评

1. 复制 `TEMPLATE.md` 到对应分类目录，改个文件名（建议用片名拼音或英文，如 `shawshank.md`）
2. 填写 frontmatter（`---` 之间的部分）
3. `> ` 开头的那一行是摘要（列表页显示）
4. 下面正常写文章正文

## Frontmatter 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| `title` | 中文片名 | `肖申克的救赎` |
| `sub` | 英文名+年份 | `The Shawshank Redemption · 1994` |
| `year` | 上映年份（数字） | `1994` |
| `director` | 导演 | `弗兰克·德拉邦特` |
| `duration` | 时长 | `142 分钟` 或 `6 集` |
| `rating` | 评分（满分10，可小数） | `9.5` |
| `tags` | 标签列表 | `[监狱, 自由, 希望]` |
| `poster` | 海报图片路径（可留空） | `reviews/movie/shawshank.jpg` |

## 注意事项

- `rating` 超过 10 会截断为 10，低于 0 会变 0
- `poster` 留空时显示默认🎬图标
- `:::spoiler ... :::` 块会渲染成带样式的剧透框
- 文件名随意，不影响排序（按文件名字母序排列）
